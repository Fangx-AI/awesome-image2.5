# 常见问题

[首页](../README.md) · [文档导航](README.md) · [安装与使用](getting-started.md)

**只想看图和复制提示词，也要安装吗？**  
不需要。先打开[分类图谱](../skills/image25/references/gallery.md)，展开 Prompt。只有调用生成工具才需要相应运行环境。

**为什么有的图片没有完整提示词？**  
外部作者可能只公开图片或短指令。页面会链接到原页；本类练习提示词是独立新编内容，不是该图的原始提示词。想直接拿到完整文本，可选[本项目案例](../skills/image25/references/visual-gallery.md)。

**图片加载不出来怎么办？**  
部分图片由上游原始地址提供，需要网络。点击案例中的原始出处确认是否可访问；如果源图已移除，可[报告失效链接](https://github.com/Fangx-AI/awesome-image2.5/issues/new?template=correction.md)，附案例页地址即可。

**案例命令提示找不到 assets 或 prompt.txt？**  
CLI 安装不包含仓库图片。`assets/` 示例需在克隆后的仓库根目录运行；自建的 `prompt.txt` 要先保存。只安装 Skill 时，直接复制提示词并提供参考图，或者按[安装指南](getting-started.md#cli)准备仓库。

**为什么安装了 Skill 还不能生图？**  
Skill 提供任务处理方法。实际生成需要宿主的生图工具，或者单独安装 CLI 并配置官方 API Key。

**为什么宿主工具生成的图片没有标为 Flare / Sunburst？**  
只有生成工具或 API 记录披露了精确模型，才能准确标注。不能仅凭图像效果判断模型。

**为什么相同提示词结果不同？**  
生成具有随机性，模型版本与运行参数也会影响输出。本 CLI 没有提供虚构的固定种子选项。

**能否一次生成所有提示词？**  
使用批量清单可以顺序调用 API。先挑选与你的用途相关的场景，dry-run 核对任务；每项实际生成都会按账户规则计费。

**为何变体单独标注？**  
变体强调同一场景的不同生产要求，适合做针对性迭代，不等于新增了一个独立创作场景。

**提示词中出现“概念”是什么意思？**  
UI、包装、建筑和教学图解首先是视觉草图。分别需要交互实现、制作规范、工程复核或事实审核后才能用于相应专业交付。

**CSV、JSONL、CLI 与分类图谱内容一致吗？**  
CSV、JSONL 和 CLI `catalog` 都来自 `catalog/recipes.json`，是未出图实验配方，可离线检索。31 类作品图谱另由来源记录和实图案例生成，包含图片、作者入口与证据状态，两者不是同一个集合。

**输出图已经存在怎么办？**  
选择一个新文件名。工具不会覆盖已有图或其元数据，也不会自动重复失败请求。

仍未解决时，按[支持说明](../SUPPORT.md)提交复现步骤与去除私人信息的错误输出。
