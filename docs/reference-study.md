## 案例组织方法

参考项目的强项是把提示词写成具体的设计规格：多面板给出每格任务，UI 给出信息架构，科研图给出节点和箭头，产品图拆开材质与布光，编辑给出不变量。我们的分类文件将这些方法落成不同的起始 Prompt，而非替换几个名词生成大量变体。

新增的 31 份练习 Prompt 明确标为 `prompt-only`；它们不冒充来源作品的原始提示词。已有原创实图保留完整 Prompt 与实际缺陷。旧版案例保留完整许可和原始来源。

## Skill 运行方式

生成 Skill：判定交付物 → 分类索引 → 最相关文件 → Craft → 原有 CLI / 宿主生图能力 → 检查输出。反推 Skill：观察真实图像 → 识别关键视觉关系 → 读取对应媒介指南 → 输出可复用提示词。精确型号、原始 Prompt 和相机参数无法由画面可靠反推。

## 仍未完成的对标项

- 多作者的 Image 2.5 实测覆盖仍不足，不能用旧版样例补成已验证数量。
- 部分来源没有公开完整 Prompt、输入图或参数。
- 反推 Skill 尚缺一组可核查的独立重建实测；首页没有把普通编辑案例改称反推结果。
- 当前未声称已在所有 Agent 运行时完成安装和执行验收。

这些是内容与验证缺口，增加在线图片页不能解决它们。
