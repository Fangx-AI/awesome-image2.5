# 中文提示词模板

[返回资源导航](../README.md)

以下为原创、尚未做出图验证的模板。替换方括号内的内容；是否支持负面提示词、参考图和种子取决于所用模型与工具。需要精确文字排版时，可在生成背景后使用设计工具完成排版。

## 1. 产品摄影

```text
为[产品]创作一张商业产品摄影图。
主体放在[材质]台面上，背景为[颜色]，画面只保留一个产品。
使用三分之四侧面视角，主体位于右侧，左侧保留约三分之一的干净空间。
柔和的棚拍主光，细腻的接触阴影，突出[关键材质]的表面质感。
保持产品结构合理。不添加品牌、水印、文字或无关配件。
```

观察：结构是否合理、边缘是否完整、留白是否足够。

## 2. 中文活动海报

```text
设计一张主题为[活动主题]的竖版海报。
主视觉为[主体]，配色为[主色]与[辅助色]，风格为[风格]。
画面上方放置标题“[准确标题]”，下方放置副标题“[准确副标题]”。
标题最大，副标题次之，背景细节减少，保持清晰的阅读层级。
只出现上述两段文字，不添加其他字符、标识或水印。
```

观察：逐字检查文字，确认日期、数字和标点。生成后仍应人工校对。

## 3. 文章封面

```text
为一篇讨论[文章主题]的文章创作横版封面。
用[具体物件]和[具体动作]表达[核心观点]。
画面只有一个视觉焦点，主体位于中下区域，上方保留标题空间。
采用[摄影/插画/拼贴]风格，配色限制为[两到三种颜色]。
在缩略图尺寸下仍能识别主体。不生成任何文字。
```

观察：缩小后主题是否清晰；隐喻是否需要额外解释。

## 4. 角色设定表

```text
创作一个[角色描述]的角色设定表。
同一画面从左到右展示正面、侧面和背面，全身，站姿自然。
三视图的发型、服装、配色、配饰与身体比例保持一致。
背景为纯浅灰色，光照均匀，无复杂阴影。
角色特征：[三到五项可观察特征]。
各视图之间保留间距，不添加文字标签。
```

观察：配饰数量、衣服结构和颜色是否在不同视图一致。

## 5. 参考图局部编辑

需要支持图像输入与编辑的模型；若工具支持蒙版，可同时标记修改区域。

```text
以输入图片为基础，只将[目标区域或物件]修改为[目标效果]。
保持人物身份、面部特征、姿势、相机视角与其余物体位置一致。
新内容的光照方向、阴影、透视与原图匹配。
保留原始画面比例，不新增其他物体或文字。
```

观察：将输出与原图并排比较，检查修改区域以外是否发生变化。
