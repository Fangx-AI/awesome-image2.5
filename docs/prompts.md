# 把提示词用到自己的作品里

[首页](../README.md) · [文档导航](README.md) · [选择分类](../skills/image25/references/gallery.md)

只看作品、复制提示词不需要安装程序或配置 API Key。

## 1. 找到可以复用的内容

从分类页选图，展开下方的 **Prompt**。代码块可使用 GitHub 的复制按钮；只有“原作者提示词”链接时，到原页查看已公开的内容。

| 页面里的内容 | 怎样使用 |
| --- | --- |
| 作品对应的完整提示词 | 作为改写起点，同时读取参考图与生成条件 |
| 原页入口或短指令 | 到原页补足上下文；缺失的完整提示词不代表已经提供 |
| 本类练习提示词 | 独立的写法示例，尚未出图，与旁边来源图片不构成输入输出关系 |
| GPT Image 2 旧版参考 | 学习构图与表达；改用新模型后重新观察结果 |

第一次使用，可从[中文茶饮海报](../skills/image25/references/showcase/tea-campaign.md)开始；学习编辑可打开[猫咪围巾案例](../skills/image25/references/showcase/pet-scarf.md)，同时查看输入图。

## 2. 改清楚四件事

1. **替换什么：** 主体、品牌、人物或商品，写出必须准确的特征。
2. **文字是什么：** 将每段文字单独列出，给出准确字符串与位置。
3. **保留什么：** 构图、色彩关系、光线或参考身份。
4. **用于哪里：** 画幅、留白区域和交付用途；具体尺寸另设工具参数。

例如，把茶饮海报改为书店活动，可以向 Agent 提交：

```text
参考茶饮海报案例的上下层级与留白，改成书店读书会海报。
标题必须是“周末一起读书”，副标题是“周六 14:00”。
主视觉换成一本展开的书和一杯咖啡，使用米白与深绿色。
竖版构图，底部留出报名信息空间，不生成二维码或其他文字。
先给我改写后的完整提示词。
```

## 3. 选择运行方式

- **已有生图工具：** 粘贴改写后的提示词；编辑任务同时上传参考图，顺序与提示词一致。
- **用 Agent：** [安装生成 Skill](getting-started.md#skills)，告诉它交付目标与参考案例。
- **用 CLI：** 将完整文本保存为 UTF-8 文件，按[安装指南](getting-started.md#first-run)预检并生成。

## 4. 检查后再继续

先看文字和结构，再看风格。一次修正一个主要问题；编辑时列出必须保持的区域。参考[质量检查表](quality.md#每张图的检查)与[完整工作流](workflows.md)。

找不到合适实图时，再去[提示词实验区](../skills/image25/references/prompt-lab-index.md)探索。CLI 的 `catalog` 与 `--recipe` 检索的是这套实验配方，不检索全部外部来源作品。
