## Install a Skill

In Codex with `$skill-installer`, send this as a chat message, not a terminal command:

```text
$skill-installer
Install image25 from:
https://github.com/Fangx-AI/awesome-image2.5/tree/main/skills/image25
```

In your next turn, try:

```text
Use image25 to adapt the packaging example for three tea flavors.
Keep a consistent brand layout. Give me the prompt first, without generating yet.
```

To extract a prompt from a reference image, install the second Skill:

```text
$skill-installer
Install image25-reverse-prompt from:
https://github.com/Fangx-AI/awesome-image2.5/tree/main/skills/image25-reverse-prompt
```

Attach an image and ask it to describe the composition, lighting and materials as a reusable prompt. It describes visible content; it cannot recover an undisclosed original prompt or model.

Other Skill-capable agents should import the entire Skill folder, including `references/`, according to their own installation instructions. Runtime paths differ, and this project has not tested every runtime end to end.

Skills do not include API credentials, install the CLI or download repository images. A host image tool can be used when available. Exact-model requests need a tool that exposes that model or an appropriate API account.

## Use the CLI

With Python 3.10+, Git and uv installed:

```sh
uv tool install git+https://github.com/Fangx-AI/awesome-image2.5
image25 -p "A small ceramic fox on a pale green background" --dry-run
```

Without uv, install with `python -m pip install git+https://github.com/Fangx-AI/awesome-image2.5` instead. A successful dry run prints request JSON. It needs no API key and does not generate or bill for an image.

For a live request, set `OPENAI_API_KEY` in your current terminal. Replace the placeholder locally; never post a real key in an issue or chat.

PowerShell:

```powershell
$env:OPENAI_API_KEY = '<your-key>'
```

Bash / zsh:

```sh
export OPENAI_API_KEY='<your-key>'
```

Save a prompt as UTF-8 `prompt.txt`, then run:

```sh
image25 --prompt-file prompt.txt --model flare --size 1024x1536 --dry-run
image25 --prompt-file prompt.txt --model flare --size 1024x1536 -o generated/poster.png
```

The second command calls the API and requires account access. It writes the image and `generated/poster.png.json`, containing the request details. Existing files are not overwritten. No automatic retry is made on failure.

### Reuse a repository edit example

CLI installation does not include `assets/`. Clone the repository before using its example paths:

```sh
git clone https://github.com/Fangx-AI/awesome-image2.5.git
cd awesome-image2.5
image25 --prompt-file assets/showcase/pet-scarf.txt -i assets/showcase/pet-portrait.png --model sunburst -o generated/pet-scarf.png --dry-run
```

Remove `--dry-run` when ready to generate. Compare the face, fur, pose and background against the input, as well as checking the added scarf.

## CLI options

| Option | Purpose |
| --- | --- |
| `-p`, `--prompt-file`, `--recipe` | Choose one: text, UTF-8 file or offline recipe ID |
| `--model` | `flare` (default), `sunburst`, or their full model IDs |
| `-i` | Local reference image; repeat for multiple inputs, in prompt order |
| `--mask` | Alpha PNG matching the first reference; transparent areas request edits |
| `--size` | Default `1024x1024`; use `auto` or supported dimensions |
| `--quality` | `auto`, `low`, `medium`, `high`, `xhigh`, `max` |
| `--background` | `auto`, `opaque`, `transparent` |
| `--format` | `png`, `jpeg`, `webp`; transparent output needs PNG or WebP |
| `-o` | Output path with a matching extension |
| `--dry-run` | Validate and print the request without an API call |

[Detailed API notes](../skills/image25/references/api.md). The CLI uses the official endpoint and reads the process environment; it does not load `.env` automatically.

`image25 catalog "poster" --kind original` searches the unrendered recipe library, not every source-gallery image. `image25 catalog --show chinese-poster` prints a complete recipe. To preview the repository batch example, use `image25 batch examples/batch.json --dry-run`; its relative output paths resolve under `examples/`.

## If something goes wrong

- **Command not found:** check your tool or Python scripts directory is on PATH.
- **Missing file:** create the prompt file or run `assets/` commands from the cloned repository root.
- **401 / 403:** check API credentials and model access.
- **429:** check your account's limits before retrying.
- **Timeout:** the server may already have processed the request; check before submitting it again.
- **Missing source image:** follow the original source link and [report the broken case](https://github.com/Fangx-AI/awesome-image2.5/issues/new?template=correction.md).

CLI and Skill installations update separately. Preserve local Skill customizations when comparing with the latest repository version.
